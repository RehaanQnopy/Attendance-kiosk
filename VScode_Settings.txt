================================================================================
PROBLEM STATEMENT: CORRUPTED JAVA INTERACTION / MISSING AUTO-IMPORTS IN VS CODE
================================================================================

* Symptom: 
  Spring Boot annotations (like @Service, @RestController, or @Autowired) 
  stop triggering automatic imports or Quick Fix suggestions (Ctrl + .).
  
* Primary Causes:
  1. The Red Hat Java Language Server cache gets bloated or corrupted.
  2. Syntax errors in the 'settings.json' file freeze the editor's engines.
  3. The build tools (Maven pom.xml or Gradle) desynchronise from VS Code.

================================================================================
TROUBLESHOOTING STEP-BY-STEP PROCEDURE
================================================================================

STEP 1: ENFORCE VALID SETTINGS CONFIGURATION
--------------------------------------------------------------------------------
Broken JSON syntax in your global configuration will immediately break 
IntelliSense features

1. Open the Command Palette ([ Ctrl/Cmd + Shift + P ]).
2. Search for: Preferences: Open User Settings (JSON)
3. Ensure your file completely mimics this baseline layout with zero floating rules:

{
  "chat.unifiedAgentsBar.enabled": true,
  "redhat.telemetry.enabled": true,

  "java.completion.enabled": true,
  "java.completion.maxResults": 0,
  "java.completion.matchCase": "off",
  "java.completion.importOrder": [
    "java",
    "javax",
    "jakarta",
    "org",
    "com"
  ],

  "editor.tabCompletion": "on",
  "editor.acceptSuggestionOnEnter": "on",
  "editor.suggestOnTriggerCharacters": true,
  "editor.quickSuggestions": {
    "other": "on",
    "comments": "off",
    "strings": "on"
  },
  "editor.quickSuggestionsDelay": 5,
  "editor.suggest.snippetsPreventQuickSuggestions": false,

  "editor.codeActionsOnSave": {
    "source.organizeImports": "explicit"
  },
  "explorer.compactFolders": false
}


STEP 2: REBUILD THE JAVA LANGUAGE SERVER (Most Common Fix)
--------------------------------------------------------------------------------
When the internal indexing engine crashes or freezes, clearing the workspace 
forces a clean rebuild of your project dependencies.

1. Open the Command Palette:
   - Windows/Linux: Press [ Ctrl + Shift + P ]
   - Mac: Press [ Cmd + Shift + P ]
2. Type exactly: Java: Clean Java Language Server Workspace
3. Select it from the dropdown list.
4. When prompted, click "Restart and Delete" (or "Restart").
5. Wait for the status bar at the bottom to finish indexing your project.
